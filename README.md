# 🍳 Кулинарный Блокнот (Culinary Notebook)

Скевоморфное приложение-блокнот для хранения и удобной готовки рецептов с офлайн-базой данных IndexedDB и параллельными таймерами.

![iOS Offline Notebook](public/icon-512.png)

---

## ✨ Основные возможности
* **Офлайн-база данных (IndexedDB):** Данные и фотографии хранятся прямо в браузере / приложении, без внешних серверов.
* **Автоматический парсер рецептов:** Распознавание текста из буфера обмена (заголовок, порции, ингредиенты с заменам, этапы и таймеры).
* **Режим «Шеф-повар»:** Полноэкранная контрастная навигация с крупным шрифтом для готовки на расстоянии вытянутой руки и свайп-навигацией.
* **Параллельные таймеры:** Независимый отсчет времени для нескольких блюд одновременно.
* **Экспорт и Постеры:** Печать A4, создание красивых карточек-постеров для соцсетей и бекап в `.json`.

## 🚀 Автоматический релиз на GitHub (CI/CD)

Проект полностью настроен для **полностью автоматической сборки и публикации релизов сразу после экспорта из Google AI Studio**.

### Как работает автоматический релиз:

1. **При выгрузке (Push) в ветку `main` / `master`:**
   - GitHub Actions автоматически запускает workflow `.github/workflows/release.yml`.
   - Система **автоматически вычисляет новую версию** (`v1.0.<run_number>`), создает Git Tag и открывает релиз с историей изменений.
   - Запускается параллельная матрица сборщиков на серверах **Windows, macOS и Ubuntu**.

2. **Ручной запуск с произвольной версией (Workflow Dispatch):**
   - Во вкладке **Actions** -> **Automated Multi-Platform Desktop & Web Release** -> **Run workflow**.
   - Можно ввести любую версию (например, `v1.2.0`).

3. **Создание через Git Tag:**
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```

### Что происходит автоматически:
- 🪟 **Windows:** Создаются установочный файл (`Setup.exe`) с выбором папки и иконкой на рабочем столе, а также переносная версия (`Portable.exe`).
- 🍏 **macOS:** Создается установочный образ (`.dmg`) и архив (`.zip`).
- 🐧 **Linux:** Создаются портативный исполняемый пакет (`.AppImage`) и стандартный пакет (`.deb`).
- 🌐 **GitHub Pages:** Автоматически обновляется веб-версия приложения.
- 📦 **GitHub Releases:** Создается публичный релиз с прикрепленными дистрибутивами для всех платформ и авто-сгенерированным чейнджлогом.

## 🛠 Локальная разработка и сборка

### Установка зависимостей
```bash
npm install
```

### Запуск веб-версии
```bash
npm run dev
```

### Запуск Electron десктоп-приложения
```bash
npm run electron:dev
```

### Сборка дистрибутивов для текущей системы
```bash
npm run electron:build
```
Готовые бинарные файлы будут сохранены в папку `release/`.
